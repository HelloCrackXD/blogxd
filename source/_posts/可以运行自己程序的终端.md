最近vibe了一些方便我用的小程序，因为没装啥框架，就都是让ai写在命令行运行的  
正好用powershell用的比较多，就突发奇想想把我的这些程序都用shell式的命令打包起来  
比如我为了搞这个博客，让ai帮我写了一个压缩图片的小程序，那我就可以在我的这个集成终端中用某个命令来直接调用这个程序，比如：  
>compact path  
>compact -i path  

## 命令样例  
这里的-i参数的意思是init，就是全按默认参数调用我的压缩程序，如果没有这个参数就会在终端中打开压缩程序并自动填入path，剩下的参数要我在打开的程序中自己填  
我觉得这相当有意思，所以我简单畅想了一下这个程序可以支持的命令与参数：  
>compact -i path ，用来调用压缩图片的程序  
>get sound -i path ，get将来可能会是一个系列命令，比如get video（仅获得视频），get sound（仅获得音频），等等，所以把get单独拿了出来，然后sound命令是调用获得视频中音频的程序  
>cut /\*1,2\*/ path ，这个命令用来剪掉音/视频中的前几秒，未来可能会加入剪去中间的特定几秒这种参数，所以用了/\*和\*/把参数包住，这里可以用-i替换  

可能以后还会有别的命令，但我目前就写了这些程序，先用这些  
## 开发过程  
说是开发，实则vibe，所以第一步我便要确认这个程序的具体功能  
所以我简单写好了项目要求  

## 目前支持的所有命令
>compact -i path ，用来调用压缩图片的程序  
>get sound -i path ，获取视频中的音频  
>cut -i path ，这个命令用来剪掉音/视频中的前几秒
